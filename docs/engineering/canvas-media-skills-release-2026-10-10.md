# 画布媒体与技能修复（2026-10-10）

云端工作流在观察暂停后仍可能完成，画布现在会先读取同一任务的结果，并在必要时恢复观察，已完成的视频可归档到原项目。恢复路径处理多个视图同时续查的竞争，不重新提交生成。局部任务仍保留手动恢复边界。

长连线的流动采用静态 SVG 路径及浏览器原生虚线动画，保留端口、交互、离屏裁剪、隐藏暂停和减少动态效果支持。移除逐帧 React 更新、曲线重采样与滤镜工作；浏览器核查证明动画推进，未承诺所有设备的固定帧率。

画布图片复制可写入系统 PNG 剪贴板。原始 PNG 保留字节，其他格式按实际像素转换；桌面 IPC 只接受当前画布传来的图片字节，并检查格式、解码、大小和尺寸，兼容固定 Electron 版本的异步剪贴板接口。内部节点复制、文本编辑和输入法保持各自行为。

本地 SKILL 支持按当前消息中的字面关键词选择显式声明的参考文件。路由不执行脚本、正则或表达式，不递归发现 Markdown 链接；保留参考目录、文件格式、总量和重复项限制。安装的个人技能内容属于本地用户数据，与通用路由代码分开保存。

验证：累计候选与已通过验收的文件逐一核对 SHA-256。同一源码版本的完整 check 包含类型检查、15 个测试文件/169 项测试、画布与启动器构建；另有实际 Electron 视频显示、动画、图片剪贴板和本地技能核查。发布前补充只读差异审查及原生项目备份的隔离恢复、SQLite 重开、冲突副本和媒体哈希检查。未发起新的付费生成。

项目、媒体、个人技能、凭据、运行数据和构建产物均不进入公开源码提交。用户授权备份的创作项目通过独立私有资料仓库及发布附件保存；恢复说明随备份提供，模型凭据由目标环境另行配置。
